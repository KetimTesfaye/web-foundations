Course Reflection

Reflecting on this web foundations and system architecture journey, several key insights stand out regarding technical growth and future directions.

The most difficult concept in the course was mastering asynchronous JavaScript execution flows alongside robust error management and promise handling. Juggling `async/await` syntax with complex state transitions, API fetch validation, and UI feedback loops initially felt overwhelming. I overcame this challenge by breaking down asynchronous routines into predictable building blocks—implementing strict `try/catch/finally` blocks, centralizing reusable request handlers, and systematically testing edge cases like network timeouts and validation failures.

Based on feedback received during my capstone project, the area of my capstone I would most improve is user interface feedback granularity and defensive form validation. While the core functionality worked seamlessly, adding more refined inline error states and accessibility enhancements would elevate the application to true production quality.

Moving forward, I plan to dive deeper into advanced backend distributed systems, containerization with Docker, and cloud-native orchestration (Kubernetes) to bridge the gap between application development and scalable cloud infrastructure deployment.
